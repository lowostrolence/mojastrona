zad 1 
#include 
using namespace std;
int main() {
    int n, il=0;
    cin >> n;
    for (int i = 1; i <= n; i++)
        if (n % i == 0) il++;
    cout << il;
    return 0;
}
Program liczy liczbę dzielników całkowitych liczby n w zakresie od 1 do n.  
Dla n = 7 dzielnikami są 1 i 7 (łącznie 2 dzielniki).
Dla n = 8 dzielnikami są 1, 2, 4, 8 (łącznie 4 dzielniki).
